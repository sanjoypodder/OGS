# Universe Module

The **Universe** module represents a collection of tradable financial
instruments used throughout the OGS Smart Money AI framework.

A Universe defines the set of symbols that may participate in market
analysis, screening, portfolio construction, Smart Money analysis,
backtesting, and AI-driven strategies.

---

## Typical Universe Types

- Entire Exchange
- Market Segment
- Index Constituents
- Sector Universe
- Industry Universe
- Watchlist Universe
- Screener Universe
- Portfolio Universe
- AI Dynamic Universe
- Custom Universe

---

## Features

- Universe Metadata
- Symbol Collection
- Owner Information
- Market Classification
- Source Tracking
- Smart Money Integration
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

## Structure

```
Universe
    ├── Metadata
    ├── Symbols
    ├── Owner

    ├── Source

```
