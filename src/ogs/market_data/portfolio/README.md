# Portfolio Module

## Overview

The Portfolio module represents an investment portfolio composed of multiple trading positions. It provides portfolio-level calculations, analytics, and management features required by trading systems, portfolio management platforms, and quantitative research.

The Portfolio module integrates with the Position module and serves as the foundation for portfolio analytics, risk management, performance evaluation, and Smart Money AI components.

---

- Portfolio Domain
- Portfolio Enums
- Portfolio Validator
- Portfolio Factory
- Portfolio Collection
- Portfolio Statistics
- Portfolio Analyzer
