# OGS Smart Money AI

# Watchlist Module

The **Watchlist** module manages collections of financial instruments that
users monitor for trading, investing, screening, and Smart Money analysis.

Typical Watchlists

- Intraday
- Swing Trading
- Breakout Candidates
- Nifty 50
- Bank Nifty
- F&O Stocks
- Forex
- Commodities
- Cryptocurrency
- Long-Term Investments

---

## Features

- Watchlist Metadata
- Symbol Collection
- Owner Information
- Market Classification
- Smart Money Categorization
- Active Status
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

## Structure

```
Watchlist
    ├── Metadata
    ├── Symbols
    ├── Owner
    └── Market
```

---

The Watchlist module follows the standard OGS Smart Money AI architecture
and integrates with the Smart Money Base framework.
