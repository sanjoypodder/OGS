# Exchange Module

## Overview

The Exchange module represents a financial exchange within the OGS Smart Money AI framework. It is the parent container for one or more brokers and provides exchange-level metadata, supported markets, trading sessions, and aggregate statistics.

Examples include:

- NSE
- BSE
- NYSE
- NASDAQ
- CME
- SGX
- LSE
