# OGS Smart Money AI

# CorporateAction Module

The **CorporateAction** module represents corporate events that alter the
capital structure or ownership characteristics of listed securities.

Examples

- Stock Split
- Reverse Split
- Bonus Issue
- Cash Dividend
- Special Dividend
- Rights Issue
- Buyback
- Merger
- Demerger
- Spin-off
- Symbol Change
- Face Value Change

---

## Hierarchy

```
Market
    ↓
Exchange
    ↓
Instrument
    ↓
Corporate Action
```

---

## Features

- Corporate Action Metadata
- Action Type
- Announcement Date
- Record Date
- Ex-Date
- Effective Date
- Split / Bonus Ratio
- Cash Dividend Amount
- Status Tracking
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

The CorporateAction module follows the standard OGS Smart Money AI
architecture and integrates with the Smart Money Base framework.
