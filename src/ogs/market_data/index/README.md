# OGS Smart Money AI

# Index Module

The **Index** module represents market indices used for market analysis,
benchmarking, screening, and portfolio comparison.

Examples

- NIFTY 50
- NIFTY BANK
- NIFTY IT
- SENSEX
- FINNIFTY
- MIDCAP 100
- NASDAQ 100
- S&P 500
- DOW JONES
- FTSE 100
- DAX
- Nikkei 225

---

## Hierarchy

```
Market
    ↓
Exchange
    ↓
Index
```

---

## Features

- Index Metadata
- Exchange Information
- Market Classification
- Currency Support
- Country Information
- Base Value
- Current Value
- Constituent Count
- Validation
- Factory
- Collection
- Statistics
- Analyzer
