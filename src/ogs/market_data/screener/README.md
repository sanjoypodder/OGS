# Screener Module

The **Screener** module provides configurable screening rules for filtering,
ranking, and selecting financial instruments based on technical,
fundamental, Smart Money, and AI-driven criteria.

Typical Screeners

- Smart Money Concepts
- Breakout
- Volume Spike
- Momentum
- Relative Strength
- Value Investing
- Growth Investing
- Dividend Stocks
- Swing Trading
- Intraday
- AI Trading
- Custom Filters

---

## Features

- Screener Metadata
- Filter Collection
- Market Classification
- Owner Information
- Sort Configuration
- Smart Money Classification
- Technical & Fundamental Support
- AI-based Screening
- Validation
- Factory
- Collection
- Statistics
- Analyzer
