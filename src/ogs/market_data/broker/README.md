# Broker Module

## Overview

The Broker module represents a brokerage firm or execution venue within the OGS Smart Money AI framework. It is responsible for maintaining broker information, supported markets, connected trading accounts, and operational capabilities.

This module serves as the parent of one or more trading accounts and provides broker-level analytics.
