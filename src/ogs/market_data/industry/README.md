# OGS Smart Money AI

# Industry Module

The **Industry** module represents industries within a sector and provides
fine-grained classification for securities, market analytics, screening,
portfolio construction, and Smart Money sector rotation.

Examples

- Private Banks
- Public Sector Banks
- IT Services
- Software Products
- Pharmaceuticals
- Biotechnology
- Oil & Gas Exploration
- Power Generation
- Cement
- Steel
- Automobile Manufacturing
- Insurance

---

## Hierarchy

```
Market
    ↓
Sector
    ↓
Industry
```

---

## Features

- Industry Metadata
- Sector Association
- Market Classification
- Country Information
- Industry Description
- Active Status
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

The Industry module follows the standard OGS Smart Money AI architecture
and integrates with the Smart Money Base framework.
