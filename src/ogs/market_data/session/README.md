# OGS Smart Money AI

# Session Module

The **Session** module represents a trading session of an exchange.

Examples

- NSE Regular Session
- NSE Pre Open
- NSE Closing Session
- NYSE Regular
- NASDAQ After Hours
- CME Electronic Session
- Binance 24x7 Trading

---

## Hierarchy

```
Market
    ↓
Exchange
    ↓
Session
```

---

## Features

- Trading Session Metadata
- Session Type
- Trading Hours
- Exchange Association
- Time Zone
- Trading Status
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

The Session module follows the common OGS Smart Money AI architecture and integrates with the Smart Money Base framework.
