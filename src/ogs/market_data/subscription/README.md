# Subscription Module

The Subscription module manages subscriptions between market data providers and
consumers within the OGS Smart Money AI framework.

## Features

- Live market subscriptions
- Historical subscriptions
- Symbol subscriptions
- Feed subscriptions
- Provider subscriptions
- Validation
- Factory creation
- Collection management
- Statistics
- Analysis

## Components

- Subscription
- SubscriptionValidator
- SubscriptionFactory
- SubscriptionCollection
- SubscriptionStatistics
- SubscriptionAnalyzer
