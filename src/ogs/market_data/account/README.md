# Account Module

## Overview

The Account module represents a brokerage or trading account within the OGS Smart Money AI framework. It serves as the parent container for one or more portfolios and provides account-level balances, margin information, leverage, and analytics.

The module integrates with the Portfolio module and forms the foundation for broker connectivity, account monitoring, risk management, and portfolio administration.
