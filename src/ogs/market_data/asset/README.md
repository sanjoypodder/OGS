# OGS Smart Money AI

## Asset Module

The **Asset** module represents the underlying financial asset within the OGS Smart Money AI framework.

An Asset is the entity being traded, independent of any exchange or derivative contract.

Examples:

- Apple Inc.
- Reliance Industries Ltd.
- Bitcoin
- Gold
- USD
- Crude Oil
- NIFTY 50 Index

### Features

- Asset metadata
- Asset classification
- Validation
- Factory creation
- Collection support
- Statistics
- Analyzer

### Module Structure

```
Market
 └── Exchange
      └── Asset
            └── Instrument
                  └── Contract
```

The Asset module follows the same architecture and coding standards as all other OGS Market Data modules.
