# Quote Module

The Quote module represents a real-time or historical market quote within the
OGS Smart Money AI framework.

## Features

- Live market quotes
- Historical quotes
- Simulated quotes
- Bid/Ask management
- Spread calculation
- Mid-price calculation
- Validation
- Factory creation
- Collection management
- Statistics
- Analysis

## Components

- Quote
- QuoteValidator
- QuoteFactory
- QuoteCollection
- QuoteStatistics
- QuoteAnalyzer
