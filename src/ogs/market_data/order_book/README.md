# OGS Smart Money AI - OrderBook Module

## Overview

The OrderBook module represents market depth for a financial instrument.

It provides a standardized structure for storing bid and ask levels,
performing validation, collecting order books, generating statistics,
and supporting Smart Money analysis.

## Components

- OrderBook domain model
- OrderBookType enumeration
- OrderBookStatus enumeration
- OrderBookValidator
- OrderBookFactory
- OrderBookCollection
- OrderBookStatistics
- OrderBookAnalyzer

## Future Integration

This module is designed to support:

- Liquidity Analysis
- Market Depth Analysis
- Order Flow
- Liquidity Sweep Detection
- Fair Value Gap Detection
- Smart Money Concepts
- Institutional Order Analysis
