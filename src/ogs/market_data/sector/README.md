# OGS Smart Money AI

# Sector Module

The **Sector** module represents economic and market sectors used to classify
financial instruments for analysis, screening, portfolio construction, and
performance comparison.

Examples

- Banking
- Information Technology
- Pharmaceuticals
- FMCG
- Auto
- Energy
- Metals
- Realty
- Infrastructure
- Telecom
- Healthcare
- Financial Services

---

## Hierarchy

```
Market
    ↓
Sector
```

---

## Features

- Sector Metadata
- Market Classification
- Country Information
- Parent Sector Support
- Description
- Active Status
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

The Sector module follows the standard OGS Smart Money AI architecture and
integrates with the Smart Money Base framework.
