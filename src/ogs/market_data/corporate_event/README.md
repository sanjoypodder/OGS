# CorporateEvent Module

The **CorporateEvent** module represents corporate actions and market events
that affect listed securities throughout the OGS Smart Money AI framework.

It provides a standardized representation of announcements,
effective dates, event classifications, and lifecycle status.

Typical use cases include:

- Earnings Announcements
- Dividend Events
- Stock Splits
- Reverse Splits
- Bonus Issues
- Rights Issues
- IPO/FPO
- Buybacks
- Mergers
- Acquisitions
- Spin-offs
- Listing & Delisting
- Symbol Changes

---

## Features

- Corporate Event Identification
- Exchange Association
- Market Association
- Instrument Association
- Event Name
- Event Date
- Effective Date
- Event Description
- Event Classification
- Validation
- Factory
- Collection
- Statistics
- Analyzer

---

## Structure

CorporateEvent
├── Exchange
├── Market
├── Instrument
├── Event Name
├── Event Date
├── Effective Date
├── Description
├── Event Type
└── Status

---

The CorporateEvent module follows the standard
OGS Smart Money AI architecture and integrates
with Settlement, Calendar, Instrument,
